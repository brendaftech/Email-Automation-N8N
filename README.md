<h1 align="left">📩🤖 AGENTE DE AUTOMAÇÃO DE EMAILS</h1>

###

<h2 align="left">❓O QUE É O PROJETO?</h2>

###


<h3 align="left">Este projeto consiste em um agente automatizado que envia emails de forma automática utilizando a plataforma n8n.<br>Basta informar para quem enviar, o assunto e a assinatura, e o sistema se encarrega de gerar e enviar o email.</h3>

###

<h2 align="left">⚙️ COMO FUNCIONA?</h2>

###

<h3 align="left">O funcionamento é simples e direto:<br><br>📩 O usuário envia as informações (destinatário, assunto e assinatura)<br>🌐 A requisição é enviada para o webhook<br>🔔 O webhook é acionado automaticamente<br>⚙️ O n8n processa os dados e executa o envio do email</h3>

###

<h2 align="left">✉️ O QUE O USUÁRIO PRECISA INFORMAR?</h2>

###

<h3 align="left">Para que o email seja enviado corretamente, é necessário fornecer:<br><br>-Destinatário (para quem será enviado);<br>-Assunto do email;<br>-Forma de assinatura (como deseja finalizar o email).</h3>

###

<h2 align="left">🤖 O QUE O SISTEMA FAZ?</h2>

###

<h3 align="left">Após receber as informações, o sistema:<br><br>-Organiza o conteúdo do email;<br>-Gera o texto automaticamente integrado com a IA;<br>-Realiza o envio do email de forma automática.</h3>

###
